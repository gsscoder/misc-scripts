# Misc Scripts

Collection of **various scripts** with no usage instructions and **no warranties**. Completely **free** to use.

## Windows Explorer & Registry Cleanup

- `wipe-openwith-entry.ps1`: removes dead "Open With" context menu entries from Windows Explorer
- `wipe-mega-leftovers.ps1`: removes MEGA Sync leftover folders from Windows Explorer
- `clean-edge-profiles.ps1`: cleans Microsoft Edge profile cache (except Default)

## Utilities

- `print-tree.ps1`: pretty prints a directory tree to console

## Development & Tools

- `start-n8n-with-ngrok.ps1`: starts n8n in Docker with volume and ngrok
- `setup-jupyterlab.ps1`: sets up a JupyterLab environment

## Email & Data Management

- `gmail-cleaner.py`: cleans up a long-neglected Gmail inbox (by month and year)
